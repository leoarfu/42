MOBILE-08

Architecture Comparison, Revisited

Requires everything above. Same players as MOBILE-2, same running example, now explained through the machinery instead of just named.

1. The running example

A single UE has no terrestrial coverage and sends a text message. Traced through three architectures below.

2. Traced through Starlink Mobile

UE speaks unmodified LTE, unaware it's talking to a satellite (MOBILE-4 §5). Satellite relays transparently (MOBILE-5 §1) — no onboard processing, no NTN-specific PHY/MAC/RRC behavior, because none of that exists in this path (MOBILE-4 §2). Ground gateway hands the message into the partner MNO's existing terrestrial core (MOBILE-6 §4), which routes it exactly as if it arrived from a normal cell tower. Fast, simple, and it works today precisely because every layer stayed as close to terrestrial-standard as possible.

3. Traced through IRIS² (as designed)

UE, in the fullest regenerative-NTN scenario, speaks NR-NTN — Doppler pre-compensated, extended timing advance, ephemeris-aware (MOBILE-4 §2). Satellite performs onboard gNB processing (MOBILE-5 §1), potentially with DTP-level flexible beam routing (MOBILE-5 §3). Core integration is purpose-built for sovereignty (MOBILE-6 §5), and the whole system is managed under multi-orbit SMO orchestration (MOBILE-7 §3). Slower to build, more capable, and architected so no single non-European commercial entity sits in the critical path.

4. Traced through AST SpaceMobile

UE speaks standard cellular frequencies to a very large phased-array satellite (MOBILE-5 §2, closing the handset gain gap via aperture rather than DTP flexibility or regenerative processing). Transparent payload, relayed to partner MNO cores (AT&T, Verizon) similarly to Starlink Mobile's model — the architectural bet here is entirely on satellite antenna size, not on payload processing sophistication.

5. Side-by-side — where each cuts corners and why that was rational

No one built the maximal-capability system first. Starlink Mobile cut regenerative processing and NTN standardization to ship years earlier. AST SpaceMobile cut regenerative processing too, betting on aperture size instead. IRIS² is the one player not cutting capability, because its governing constraint (sovereignty, not time-to-market) makes the regenerative/NTN/SMO-orchestrated approach the correct answer for its actual customer — European governments, not consumer subscribers.

6. The 2027 convergence

If Starlink's Gen2 D2D satellites do move to NR-NTN as reported (MOBILE-4 §6), the transparent-vs-regenerative divide in this comparison narrows at the radio-standard level — though payload architecture and core integration philosophy could easily remain different even after both speak the same radio standard. Standard convergence does not automatically mean architectural convergence — worth keeping those two things separate when this question comes up in an interview.
